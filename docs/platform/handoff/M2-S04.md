Facts found while writing the pack, which the owner and later packages need:

1. **The repository `mqusaeri/mscd` is public** (checked with `gh api repos/mqusaeri/mscd`: `"visibility":"public"`). Anyone can read its workflow logs and job summaries. The plan has `ops-cli.yml` (M2-S09) show command output in the job summary, and that output can hold organisation names and invited email addresses. GL-50 and the "Repository visibility" decision cover it, and `legal-inputs.md` question 5 asks the lawyer. For the same reason the incident contacts and the operator names stay out of the repository (deviation 7).
2. **The weekly restore test copies the full production database to a GitHub-hosted runner** (M2-S07, D-S12), which is a transfer outside Indonesia every week. GL-49 and question 5 cover it.
3. **Retention gaps in the code today:** ended session rows (with IP address and user agent), invitations, password reset rows and in-app notifications are never removed; the stored file of an expired export stays in the vault; business data is soft-deleted only (build plan C.1). They are listed in the retention table so the privacy notice can describe the real behaviour.
4. **Specific personal data can enter through free text and files**, for example ISO 37001 due diligence notes (question 12).
5. M2-S01's `saas-keys.sh` makes separate production and staging key sets and compiles both anchor public keys into the release. `owner-inputs.md` follows its file names and says that the printed lines win when they differ.
