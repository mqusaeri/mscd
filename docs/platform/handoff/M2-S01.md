### Key set layout (for M2-S02, M2-S05 and M2-S13)

`saas-keys.sh --out "$K/keys" --print-only` makes throwaway keys for tests (S-2). Use `--trusted-keys-dir "$K/keys/trusted"` and `--pack-signing-key "$K/keys/pack-signing.key"` for the images. The server secrets of a test stack are `"$K/keys/production/"{platform.key,storage.key,audit-anchor.key,audit-anchor.pub}`; the compiled trust anchors include both `production` and `staging` anchor keys, so either folder matches the image. Delete `$K` afterwards.

### `digests.json`

```json
{
  "version": "1.1.0-rc.1",
  "revision": "<40-character commit>",
  "created": "2026-10-27T05:28:48Z",
  "pushed": true,
  "attested": true,
  "server": "sha256:<index digest>",
  "web": "sha256:<index digest>",
  "serverImage": "ghcr.io/mqusaeri/mscd-server",
  "webImage": "ghcr.io/mqusaeri/mscd-web",
  "serverRef": "ghcr.io/mqusaeri/mscd-server@sha256:<index digest>",
  "webRef": "ghcr.io/mqusaeri/mscd-web@sha256:<index digest>"
}
```

With the containerd image store, the digest of a loaded image is its image index digest, the same digest a push publishes. `deploy-prod.yml` (M2-S05) reads `serverRef` and `webRef`, or `server` and `web` with `MSCD_SERVER_DIGEST` and `MSCD_WEB_DIGEST`. The cosign identity is `https://github.com/mqusaeri/mscd/.github/workflows/release.yml@refs/tags/<tag>` with issuer `https://token.actions.githubusercontent.com`.

## Follow-ups

- Dependencies (for the orchestrator, R-03): the Trivy gate refuses the current server image for `undici` 7.30.0 (CVE-2026-109869, fixed in 7.30.1) and `zod` 4.6.5 (CVE-2023-54404, fixed in 4.6.6), both pinned in `apps/server/package.json` (and `zod` in `packages/shared` and `packages/pack-tools`). Until both are raised, no release image passes the gate, on this host or on GitHub, and the OSV job fails too. Use versions at least 14 days old.
- On this host the web image keeps HIGH findings in `brotli-libs` and `curl` of the base image because the Alpine updates cannot be fetched here; GitHub runners apply them (`--release`). `nginxinc/nginx-unprivileged:1.30-alpine3.24` was pulled fresh on 27 October 2026.
- `apps/web` dependencies are not in either image's npm scan (the web image holds only built files); OSV covers them through the lockfile.
- M2-S13 (`ci.yml`): add `build-release-images.sh` and `saas-keys.sh` to the shellcheck step, and `check-workflows.mjs --self-test` next to `--saas --require-all`.
- `deploy/README.md` and `deploy/docker/README.md` (release team pages, no owner in Milestone 2) do not mention `--images-only` or `build-release-images.sh`; `tools/scripts/README.md` does not list `check-workflows.mjs`.
- Dependabot reads base images from `FROM` lines; the Dockerfiles name them through `ARG NODE_IMAGE` and `ARG NGINX_IMAGE` defaults, which Dependabot may not update. Check the first Monday run.
- CodeQL on a private repository needs GitHub Code Security; if the repository becomes private, set `MSCD_CODE_SCANNING=false` and check the licence terms.
- The OSV scanner was not run locally (running the downloaded binary was not permitted here); its arguments follow the action's documented `scan-args` form. Check the first run.
